# しらすの山

一人称3D × 物流・工場自動化 × ちりめんモンスター収集。企画書 v2.0 をもとにしたブラウザゲームです（Three.js / Vite / GitHub Pages）。

1,000万匹のしらすの山から、しらすを1匹ずつつまんで計量機に運び、パックにして売る。手に入れたお金で手袋やスコップを買い、山を削っていくと、最初から埋まっていた「ちりモン」が見つかる。見つけたら保護ケースへ。うっかり計量機に入れたまま包装すると「見逃し（誤出荷）」になる。

## 遊び方

| 歩く／見回す | WASD＋マウス（画面クリックで操作開始） | 左側ドラッグ（スティック）＋右側スワイプ |

| メニュー | Esc | ≡ |

## 実装範囲（企画書 7章の P0〜P5）

- **P0 技術検証**：一人称移動、つまむ／はなす、計量機、包装・出荷。個体は手・床・計量機・出荷済み・保護ケースのどこか1か所にだけ存在し、複製されない（記録画面の「整合性を検査」で確認できる）。
- **P1 山の実体**：1,000万匹すべてに固有ID。ワールドシードとチャンク（10cm角の柱）から位置・回転・形状を決定論的に再生成。除去状態は 1.25MB のビットセット。近景＝実モデル（InstancedMesh）、中景＝簡略メッシュ、遠景＝除去状態を反映した表面メッシュ。
- **P2 収集**：7種類のちりモンを生成時に配置（後から湧かない）。山を削ると露出、保護ケースで図鑑登録、計量機経由で出荷すると見逃し。恒久図鑑。
- **P3 物流**：手袋4段階、スコップ／大スコップ、運搬箱・台車（スコップで何度もすくってためる）。建設画面（一時停止中の上面図・0.5m グリッド）で **コンベア・ホッパー・包装機・クレーン** を設置。クレーンは可動範囲で一番高い所から実在IDを取り除き、ホッパー → コンベア → 包装機（または計量機）へ流れて出荷される。機械はちりモンを見分けないので、混ざったまま包装されると見逃し。設備は E で停止でき、ベルト・ホッパーから手で取り出せる（ちりモン優先）。
- ちりモンの配置：開始時に露出しているのは1〜2匹だけ。大半は表面から 1.4cm より深くに埋まっている（旧版のセーブは旧配置のまま）。
- そのほか：長靴・自動包装・ルーペ、画質プリセット（低／標準／高・動的解像度）、スマホ操作、設定（感度・FOV・揺れ・照準補助・文字サイズ・左手配置）、IndexedDB自動セーブ、チュートリアル。

- **P4 工場設計**：
  - 占有マス・向き・入口／出口：包装機は1×2マス（後ろの面から受け取り、正面の出荷口マスを空ける）、発電機は2×2マス＋周囲1マスの通路。コンベアは正面から受け取らず、包装機・選別機は後ろの面からだけ受け取る。
  - 人の通路：置くと計量機・棚・保護ケース・端末・受電盤・山の裾へ歩いて行けなくなる設備は置けない（グリッド上の到達判定）。
  - 電力：受電盤（3kW・無料）、発電機（12kW・負荷1kWあたり0.06円/秒の燃料費）、電柱（電線で5m先とつながり半径3mに配電）。配電範囲外の設備は動かない。不足すると優先度（高・中・低）の低い設備から停止、境目の設備は減速。
  - 選別機：ライン途中で、ちりモンを検出率85%（個体ごとに決定論的）で回収箱へ分ける。回収箱がいっぱいだと止まる。
  - 建設画面に配電範囲・電線・優先度・問題のある設備（!）を表示。HUD に電力の需要／供給。
  - P3 までのセーブ：設備がある場合は発電機1台分の費用を一度だけ支給。1マスだった包装機は、2マス目がふさがっていれば撤去して全額返金。

- **P5 マルチ端末**：
  - セーブ：IndexedDB の2つの枠に交互に保存し、読み込み時に個体の保存則で検証。壊れていれば一つ前から復元。セーブ形式の版を移行（v1→v2）し、新しすぎる版は上書きしない。永続ストレージを要求。15秒ごと・アプリ切り替え時（自動で一時停止）に保存、手動セーブあり。
  - 書き出し／読み込み：gzip＋ビットセットのRLEで数KBのファイルにし、PC ⇄ スマホでセーブを移せる（スマホは共有シート）。
  - スマホ操作：照準補助「自動」（スマホは強）、ボタンの大きさ、「はなすを長押しで実行」（誤タップ防止）、振動、全画面・横向き固定（対応端末）、建設画面のピンチ拡大。
  - 画質：解像度・近景の密度・影・描画距離・FPS表示を個別に上書き。自動画質は GPU 名も見て選び、重い状態が続くと一段下げる。描画コンテキストが失われたら保存して再読み込みを案内。

未実装（次の段階 P6）：公開向けの仕上げ（チュートリアルの磨き込み、UI、テスト追加）。大規模化（増設床・蓄電設備・複数ライン）は企画書 3.1 の後半要素。

数値（1パック＝20匹＝20円 など）は `src/config.js` にまとめた仮値です。

## 開発

```sh
npm install
npm run dev     # 開発サーバー
npm test        # 山モデル・保存則・搬送・電力・セーブ形式のテスト（P0〜P5 の合格条件）
npm run build   # dist/ に静的ビルド
```

## 公開（GitHub Pages）

`main` に push すると `.github/workflows/deploy.yml` がテスト → ビルド → Pages へデプロイします。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
